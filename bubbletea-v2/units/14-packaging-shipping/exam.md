# Unit 14 Exam

**E1 (Apply).** Design the package layout for a "notes" TUI supporting TUI, `notes list --json`, and SSH mode. Show what each imports.

**E2 (Apply).** Write `main` that: parses `--json` and `--version`; falls back to plain output when not a TTY; uses correct exit codes.

**E3 (Analyze).** Two SSH users see each other's typed text. What did the developer do wrong?

**E4 (Evaluate).** Cobra vs `flag` for this tool; justify.

**E5 (Apply).** Write a Wish middleware chain outline that requires a PTY, logs connections, and hosts your model; describe shutdown.

**E6 (Analyze).** `notes | head` prints garbage and hangs. Why and how to fix?

**E7 (Evaluate).** A release plan: which platforms/architectures, how to verify, how to distribute.

**E8 (Apply).** Implement atomic config write (temp file + rename) in Go.

**E9 (Analyze).** What breaks if you print an error inside `View` when startup fails?

**E10 (Create).** Write a pre-release compatibility test plan (10 items) across terminals/OS/sizes/color modes.
