# Further resources — Unit 3

- **`key.go` in the bubbletea repo** (source) — short, readable, the definitive list of key names; read the `Key` struct comments.
- **`UPGRADE_GUIDE_V2.md` → "Key Messages"** (repo doc) — every v1→v2 key rename in one table.
- **Bubbletea `examples/key-events`-style demos** (repo examples) — run one to build intuition; `examples/u03-keys` in this course does the same.
- **kitty keyboard protocol spec** (sw.kovidgoyal.net/kitty/keyboard-protocol) — optional deep dive on *why* legacy terminals can't tell some keys apart.
