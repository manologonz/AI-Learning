# Further resources — Unit 1

- **A Tour of Go** (interactive tutorial, go.dev/tour) — best hands-on pass over structs, methods, interfaces and closures; do the "Methods and interfaces" section.
- **Effective Go** (official doc, go.dev/doc/effective_go) — read only "Methods" and "Interfaces and other types" for idiom, especially pointer vs value receivers.
- **Go by Example** (reference site, gobyexample.com) — short runnable snippets for type switches, closures and errors when you need a quick refresher.
- **Go Wiki: Go Code Review Comments – Receiver Type** (go.dev/wiki/CodeReviewComments) — settles the value-vs-pointer receiver question with concrete rules.
