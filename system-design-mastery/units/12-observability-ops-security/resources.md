# Further resources: Unit 12

- **Google SRE Workbook, Ch. 5: "Alerting on SLOs"** (book chapter, free at sre.google/workbook/alerting-on-slos/) — the source of the multi-window multi-burn-rate approach; the single most useful reading for this unit.
- **OpenTelemetry documentation: "Concepts" and the Node.js "Getting started"** (docs, opentelemetry.io) — the vendor-neutral standard, with a TypeScript-friendly setup for traces/metrics/logs.
- **OWASP Top 10 and OWASP API Security Top 10** (reference, owasp.org) — the canonical list of common vulnerabilities including broken object-level authorization; use it as a design-review checklist.
- **Charity Majors et al., "Observability Engineering"** (book) — explains high-cardinality debugging and why dashboards alone aren't observability.
- **AWS Well-Architected Framework: Security and Cost Optimization pillars** (docs, aws.amazon.com/architecture/well-architected) — practical checklists that map to the design dimensions in this unit, useful for design reviews regardless of cloud provider.
